# 001-ai-race

Canonical planning fixture for the first ORVYQ film. It is intentionally **not proof-ready** until:

1. `assets/audio/final_voice.wav` is supplied.
2. `direction/word_alignment.json` is generated from that exact audio.
3. Official source captures are generated by `orvyq capture-sources`.
4. Context placeholders are replaced by licensed contextual footage.
5. A licensed music cue is selected and added to the canonical plan.

The proof workflow fails closed while any of these requirements remain incomplete.
